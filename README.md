# Sales Dashboard — Electronic Products

This Python project was developed as part of a Hashtag online course. The goal was to register, visualize, and analyze sales data from a CSV database for electronic products.

*Tools Used*
- Python
- Streamlit
- Pandas
- Plotly Express

*Features*
- Register sales with the following information:
  - Date
  - Salesperson
  - Product
  - Quantity
  - Sales value
- View and filter registered sales.
- Visualize and analyze sales metrics, including total revenue and interactive charts.

*Future Improvements*
- Edit registered sales
- Delete registered sales

*Note:* This project is deployed using Streamlit Community Cloud. If the app has been inactive for a while, it may be temporarily unavailable or take a few moments to start again.

*Link:* https://sales-and-management-system.streamlit.app/
